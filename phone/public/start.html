Your real-estate agent in your pocket.

An open-source Agent Skill for Claude Code. It collects real Prague listings, shows the monthly cost and the move-in cost of each flat, and after you approve one flat it holds a live voice call in the browser to book the viewing.

Paste this into Claude Code

Set up DOMOVOY for me. 1) Run: git clone https://github.com/Skilux/domovoy ~/domovoy (git pull if it exists). 2) Symlink ~/domovoy/skill/domovoy to ~/.claude/skills/domovoy, and copy config.example.json to config.json in that folder if config.json is missing. 3) Run: python3 ~/domovoy/skill/domovoy/scripts/doctor.py check --json. 4) For each FAIL, show me its fix line and wait while I put the key into ~/.config/domovoy/.env myself. Never ask me to paste a key in chat, and never read or print that file. 5) Run the check again until nothing fails, then find me a flat to rent in Prague. To see it first with no accounts, run: python3 ~/domovoy/skill/domovoy/scripts/demo.py call and tell me the run is synthetic.

Or run it from a terminal

claude "$(curl -fsSL https://domovoy-phone.vercel.app/prompt.txt)"

  1. Real listings, honest costs

    Sreality, Bezrealitky and iDNES go into one Notion shortlist. Each flat shows two numbers: the monthly cost, and the move-in cost, which is everything you pay to move in (first month, deposit, commission, one-time fees, missing furniture). Estimated and unknown parts are named.

  2. You approve one flat

    Mark it Interested in Notion. Nobody is contacted before that.

  3. It calls and books

    The agent talks to the realtor in a live browser call, with no telephone network. A viewing lands in your calendar only inside your free windows and your budget.

The demo call is a browser voice call with a consenting demo participant. No real phone number is dialled. Built at AI Agents for the Rest of Us, Prague, 13 Nov 2026.
