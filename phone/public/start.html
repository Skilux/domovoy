DOMOVOY by (Not)Homeless.ai GitHub

Your real-estate agent in your pocket.

An open-source Agent Skill for Claude Code. It collects real Prague listings, shows the honest monthly and upfront cost, and after you approve one flat it holds a live voice call to book the viewing.

Paste this into Claude Code

Install the DOMOVOY skill from https://github.com/Skilux/domovoy (copy skill/domovoy into ~/.claude/skills/domovoy), run its setup, then find me a flat to rent in Prague.

  1. Real listings, honest costs

    Sreality, Bezrealitky and iDNES go into one Notion shortlist with the monthly total, the upfront cash and what is still unknown.

  2. You approve one flat

    Move it to Interested. Nobody is contacted before that.

  3. It calls and books

    The agent talks to the realtor. A viewing lands in your calendar only inside your free windows and your budget.

The demo call is a browser voice call with a consenting demo participant. No real phone number is dialled. Built at AI Agents for the Rest of Us, Prague, 13 Nov 2026.
